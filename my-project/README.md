# Portfolio Website

This folder contains the React + Vite portfolio website for Lymraina Dsouza.

## Overview

The portfolio website includes:
- hero section with name, summary, and contact links
- skills, education, certifications, and languages
- detailed project descriptions
- participation and achievements

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Then open the URL shown by Vite in your browser.

## Build for production

```bash
npm run build
```

## Notes

- Built with React 19 and Vite.
- Uses a custom CSS layout for responsive presentation.
